# Code of Conduct

Keepr follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
v2.1. Be kind, assume good faith, and keep discussions focused on the work.

Unacceptable behavior includes harassment, discrimination, and personal
attacks in Issues, Discussions, pull requests, or any project space.

Violations can be reported privately via
[GitHub Security Advisories](https://github.com/JustRelaXX/Keepr/security/advisories/new)
or by contacting the maintainer. Reports are handled confidentially.
