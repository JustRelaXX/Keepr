# Проверки сборки 0.1.0

Среда: Fedora 44 x86_64, Rust 1.98.1, Node.js 22, WebKitGTK 2.52.5. Дата: 13 сентября 2026.

## Автоматические проверки

- 16 Rust behavioral/property-based tests: дни/месяцы/годы, leap day, DST gap/fold, границы полуночи, откладывание, просрочка, история, отмена, повторное выполнение, разовое событие и новый цикл, перенос комнат, восстановление SQLite и резервной копии, квитанции уведомлений и повторные попытки.
- 10 проверок экспорта TypeScript-контрактов.
- 3 frontend/resource tests: полнота локализаций и параметров строк, пресеты, ограничение capabilities.
- `svelte-check`: без ошибок и предупреждений.
- `cargo clippy --workspace --all-targets -- -D warnings`: без предупреждений.
- Desktop E2E: настоящий WebKitGTK/Tauri/SQLite с изолированными данными; создание, изменение комнаты, выполнение, откладывание, календарь, журнал, полный перезапуск, удаление/отмена, английский язык и тёмная тема.
- Проверка фактического вызова системного D-Bus Notifications transport. Кнопки в уведомлениях не создаются.
- Реальный планировщик доставляет уведомление о наступившем сроке после изменения времени напоминаний/тихих часов.
- Автозапуск создаёт и удаляет корректный XDG `.desktop`-файл в изолированном домашнем каталоге теста.
- Проверка запуска с `--background`: процесс живёт, дочернего WebKit-процесса нет. Повторный background-запуск завершает второй экземпляр.

Полный desktop E2E повторно пройден на **оптимизированном release-бинаре**, включая системные уведомления, планировщик и автозапуск. Без UI измерено **около 99 MiB RSS / 48 MiB PSS**. RSS включает разделяемые GTK/system libraries; PSS учитывает их пропорциональную долю. Это кратковременный замер Linux-процесса, не Windows и не длительный нагрузочный тест.

RPM установлен на текущую Fedora. `/usr/bin/keepr` запущен в niri/Wayland; compositor подтвердил открытое и сфокусированное окно Keepr. Release executable — около 16 MiB; RPM — около 6 MiB.

## Исправлено в ходе проверки

- Изменение темы обновляет основной текст, а не только поверхности.
- Переход между разделами возвращает прокрутку к заголовку.
- Системный notification-плагин заменён на ожидаемый вызов `notify-rust`: устранены вложенный runtime и потеря ошибок доставки.
- Проверка календарных интервалов ограничивает поддерживаемый диапазон дат.
- Контраст второстепенного текста и цветов срочности усилен в светлой теме.
- Linux-автозапуск учитывает XDG_CONFIG_HOME, отсутствующий каталог конфигурации, пробелы в пути и постоянный путь AppImage.

Снимки реальных экранов находятся в `test-results/`. Windows runtime, установочный сценарий и поведение уведомлений на Windows требуют отдельного прогона на целевой ОС; конфигурация CI подготовлена.
