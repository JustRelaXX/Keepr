# Платформы и текущие границы

## Linux

Проверка ведётся на Fedora 44 (niri/Wayland), desktop E2E — в настоящем WebKitGTK под Xvfb. Tray требует AppIndicator/StatusNotifier host. Некоторые окружения, включая GNOME без соответствующего расширения, не отображают сторонние tray-иконки. Keepr остаётся доступен через launcher.

Уведомления использует сервер текущей desktop-сессии. Его настройки, «Не беспокоить» и политика рабочего окружения определяют внешний вид и показ. Названия и счётчики в tray — кроссплатформенный fallback для окружений, не показывающих заголовок иконки.

Локально собраны `.rpm` и `.deb` (примерно 6 MiB каждый), release executable — около 16 MiB. Эти артефакты собраны на Fedora 44. Для распространения на Ubuntu/Debian нужно собирать `.deb` на минимальной поддерживаемой версии дистрибутива: упаковка Fedora-бинаря в `.deb` не делает версии glibc/WebKitGTK совместимыми со старыми системами.

## Windows

Цель — Windows 10/11 x64 с WebView2. Rust/Tauri-реализация использует native-уведомления через `notify-rust`, плагины автозапуска и системный tray. Подготовлена конфигурация CI для Windows; сама CI в текущей локальной сессии не запускалась. Windows executable и installed-toast поведение здесь не исполнялись. Перед выпуском необходим smoke-test установленного NSIS-пакета: идентификация уведомлений, автозапуск, sleep/wake, пересоздание WebView и tray.

## Осознанные границы 0.1

- По текущему решению уведомления **без кнопок**. Выполнение и откладывание доступны в UI и tray. Переход в конкретную вещь кликом по native-уведомлению пока не подключён.
- Календарь показывает реальные текущие сроки. Прогноз бесконечных повторений не генерируется: дата следующего цикла зависит от фактического выполнения.
- Автозапуск включается в настройках и запускает процесс при входе пользователя. После явного выхода напоминания не работают до следующего запуска.
- На Windows используется 60-секундная контрольная сверка времени; Linux также получает сигнал resume от logind.
- Нет подписывания установщиков и автоматического обновления: для них нужны выпускная инфраструктура и ключи владельца проекта.
- Общий snapshot журнала ограничен последними 10 000 событиями; полная история остаётся в БД и резервной копии.
- Пресеты являются редактируемыми начальными значениями. Фактический срок продуктов, косметики и расходников определяется маркировкой и условиями использования.
