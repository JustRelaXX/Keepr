# Keepr 0.1.1

- В журнале у каждой записи есть кнопка корзины с доступной подписью и подсказкой.
- Удаление можно отменить кнопкой «Вернуть» во всплывающем сообщении.
- При удалении с клавиатуры фокус переходит к следующей записи; при очистке журнала — к заголовку пустого состояния.
- Можно удалять записи даже о вещах, уже удалённых из дома.
- Сроки, состояния вещей, здоровье и накопленный прогресс сохраняются.
- Удаление отражается в истории предмета и сохраняется после перезапуска и экспорта/восстановления резервной копии.
- Миграция SQLite 1 → 2 выполняется автоматически с резервной копией перед обновлением. Старые резервные копии продолжают импортироваться.

Проверено: 22 теста доменной логики/хранилища (6 новых для журнала и миграций), 10 проверок TypeScript-контрактов, 3 проверки ресурсов; Clippy и Svelte Check проходят. Desktop E2E подтвердил удаление конкретной записи, отмену, сохранение после полного перезапуска и перенос клавиатурного фокуса. Собраны RPM/DEB 0.1.1, установлен RPM на текущую Fedora. Уже работающий экземпляр нужно полностью закрыть через tray и открыть заново для применения обновления.
