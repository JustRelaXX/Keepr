# Keepr 0.1.3

- Гайд-путеводитель для первого запуска: 5 шагов по дому (здоровье,
  добавление вещи, отметка заботы, комнаты, фоновая работа).
- Показывается один раз после онбординга, не блокирует клики, закрывается
  по Esc и кнопке пропуска; повтор доступен в настройках.
- Исправлена архитектурная ловушка: тур полностью управляется событиями,
  без реактивных эффектов, поэтому не может закольцеваться с обновлениями.

Проверено: unit-тесты шагов, полный Desktop E2E (прохождение, пропуск,
повтор из настроек), Clippy, Svelte Check, Vitest. Собраны RPM/DEB/AppImage
0.1.3 и Windows NSIS, установлен RPM на текущую Fedora. Уже работающий
экземпляр нужно полностью закрыть через tray и открыть заново.
