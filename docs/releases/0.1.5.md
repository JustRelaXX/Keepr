# Keepr 0.1.5

- Первый запуск стал честным: «Добавить первую вещь» ведёт на пустой дом,
  где встречает гайд, а не сразу открывает редактор поверх него.
- Демо-дом получил баннер и кнопку «Начать с чистого дома»: все демо-данные
  удаляются одной транзакцией с подтверждением, настройки сохраняются.
  Удалять всё вручную больше не нужно.
- Флаг прохождения тура переехал из localStorage в SQLite: сброс базы или
  восстановление из копии больше не ломают гайд молча.
- Попутно поймана и исправлена гонка: асинхронное сохранение флага тура
  позволяло гайду переоткрыться; теперь пометка оптимистичная.

Проверено: 4 новых Rust-теста (совместимость старых настроек, персистентность
флага, сброс демо), unit-тесты шагов, полный Desktop E2E (прохождение тура
на пустом доме, персистентность после рестарта, сброс демо, реплей),
Clippy, Svelte Check, Vitest. Собраны RPM/DEB/AppImage 0.1.5 и Windows NSIS,
установлен RPM на текущую Fedora. Уже работающий экземпляр нужно полностью
закрыть через tray и открыть заново.
